# KV Cache 项目宪章（作战手册总索引）

> 背景：火山引擎对象存储实习（非核心）→ 目标 DeepSeek 推理团队 / KV Cache 方向。
> 核心策略：不做"空前绝后的大项目"，做**一条任何人都能复核的证据轨迹**。

## 文档清单

| 文件 | 内容 |

## 一句话总纲

**动机不是"我想做 KV cache"，而是"我测出 X 与预期不符，追查后发现 Y，这个项目为搞清楚 Y 而生"。**

## 执行循环（最小节拍）

```
每周：  测一个东西 → 撞上异常 → 归因到底 → 写一篇短笔记（哪怕 300 字）
每月：  一次上游贡献尝试（issue 复现报告 / 性能数据 / 修复 PR）
全程：  所有实验脚本和原始数据公开
```

## 双轨制

```
轨道 A（笔记本 + 公开 trace，常驻）：策略层研究 —— 零成本、产量主力
轨道 B（租用 GPU，脉冲式）：        数据通路实测 —— 验证 A 的结论
```
